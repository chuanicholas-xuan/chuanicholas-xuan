## 🤖 How I build

1. **Spec first:** requirements, design docs and a roadmap before any code.
2. **Direct the agent:** AI writes most of the code, following project rules I set (e.g. "money is always whole cents").
3. **Verify:** unit tests for the critical logic, and hands-on testing in the browser and on my phone.
4. **Ship:** web on Vercel, Android APKs built by Expo EAS or GitHub Actions.
